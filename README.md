# The Aeonomicon — Static Site

Deployable to GitHub Pages at aeonomicon.com.

## Deploy

1. Create a GitHub repo
2. Push this folder's contents to the main branch
3. In repo Settings → Pages, set source to main branch root
4. Add a CNAME record pointing aeonomicon.com to <username>.github.io

## Adding Images

Hero: place image in assets/images/ and uncomment the hero img tag in the essay HTML.
Inline: use figure + img + figcaption tags inside the .essay-body div.
